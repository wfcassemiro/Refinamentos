==============================================================================
            GUIA RÁPIDO - ESCOPOS ZOOM (FORMATO GRANULAR)
==============================================================================

⚠️  ATENÇÃO: Formato dos escopos mudou!

O Zoom agora usa formato GRANULAR com REPETIÇÃO do recurso:

❌ ERRADO (formato antigo):     ✅ CORRETO (formato novo):
   meeting:write:admin            meeting:write:meeting:admin
   meeting:read:admin             meeting:read:meeting:admin
   user:read:admin                user:read:user:admin

==============================================================================
                    ESCOPOS QUE VOCÊ DEVE ADICIONAR
==============================================================================

Acesse: https://marketplace.zoom.us/
Vá em: Manage → Build App → [Sua App] → Scopes

Marque os seguintes escopos:

📹 MEETING SCOPES:
  ✅ meeting:write:meeting:admin
  ✅ meeting:read:meeting:admin
  ✅ meeting:update:meeting:admin
  ✅ meeting:delete:meeting:admin
  ✅ meeting:update:status:admin

👤 USER SCOPES:
  ✅ user:read:user:admin
  ✅ user:write:user:admin

==============================================================================
                           APÓS ADICIONAR
==============================================================================

1. Clique em SAVE/CONTINUE
2. Aguarde 2-5 minutos (propagação nos servidores Zoom)
3. Delete o cache: rm /tmp/zoom_token_cache.json
4. Teste criando uma reunião em zoom_manage.php

==============================================================================
                        VERIFICAR SE FUNCIONOU
==============================================================================

Acesse no navegador:
  https://seudominio.com/zoom_integration_php/verificar_escopos.php

Esse script vai testar automaticamente todos os escopos!
